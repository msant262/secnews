Arquivo

Olá, leitores! Bem-vindos a mais uma edição da nossa newsletter semanal sobre segurança da informação. Esta semana, testemunhamos uma série de incidentes graves, incluindo ataques sofisticados de suprimento de software, múltiplas vulnerabilidades zero-day ativamente exploradas e campanhas APT com ampla escala. Desde scanners de vulnerabilidades comprometidos a kits de exploração móvel, o cenário de ameaças continua se expandindo. Vamos aos detalhes.

01
Crítico

Kit de Exploração DarkSword Usa 6 Vulnerabilidades, 3 Zero-Days para Comprometimento Total do Dispositivo iOS

Um novo kit de exploração para dispositivos Apple iOS está sendo usado por múltiplos atores ameaças desde novembro de 2025. Segundo relatórios do Google Threat Intelligence Group, iVerify e Lookout, o DarkSword é uma cadeia completa de exploração projetada para roubar dados sensíveis de iPhones executando iOS 18.4 a 18.7. O kit usa 6 vulnerabilidades distintas, incluindo 3 zero-days (CVE-2026-20700, CVE-2025-43529, CVE-2025-14174), permitindo acesso privilegiado e exfiltração de dados através de ataques waterhole via Safari.

Ação: Atualize imediatamente para iOS 18.7.3 ou versões mais recentes

Crítico

Trivy Vulnerability Scanner Comprometido em Ataque Sofisticado de Suprimento

Aqua Security's Trivy, um scanner de vulnerabilidades open-source amplamente adotado, foi comprometido em um ataque sofisticado de suprimento focado em CI/CD. O ator ameaça TeamPCP usou acesso de um incidente anterior não totalmente remedido para injetar malware de roubo de credenciais em binários oficiais, GitHub Actions (trivy-action, setup-trivy) e distribuições de containers. O ataque afetou 76 de 77 tags de versão nas Actions do GitHub.

Ação: Atualize para Trivy v0.69.2+, trivy-action v0.35.0, setup-trivy v0.2.6
03
Crítico

Campanha GlassWorm/ForceMemo Usa Tokens GitHub Roubados para Force-Push Malware em Repositórios

A campanha GlassWorm está sendo usada para atacar projetos Python — incluindo apps Django, código de ML, dashboards Streamlit e pacotes PyPI — através de tokens GitHub roubados. O ator compromete sistemas de desenvolvedores com malware GlassWorm (através de extensões VS Code e Cursor maliciosas), usa as credenciais roubadas para forçar mudanças maliciosas em cada repositório. Mais de 433 projetos foram afetados.

Ação: Revogue tokens GitHub comprometidos e use MFA forte

CVSS 10.0

Vulnerabilidade Crítica RCE em PTC Windchill & FlexPLM (CVE-2026-4681)

PTC reportou uma vulnerabilidade de Execução Remota de Código (RCE) através de desserialização de dados não confiáveis em produtos Windchill PDMLink e FlexPLM. CVE-2026-4681 recebeu CVSS v3.1 score de 10.0 (Crítico) - a pontuação máxima possível, afetando múltiplas versões desde Windchill 11.0 M030 até FlexPLM 13.0.3.0.

Ação: Proteja sistemas Windchill/FlexPLM e aplique workarounds Apache/IIS
05
CVSS 10.0

Vulnerabilidade Crítica RCE não Autenticada em Oracle WebLogic Server

Uma vulnerabilidade de Execução Remota de Código não autenticada (CVE-2026-21962, CVSS 10.0) no Oracle WebLogic Server Console está sob exploração imediata e ampla. O ataque permite execução de comandos de sistema operacional arbitrários através de simples requisições HTTP sem autenticação, permitindo acesso total ao servidor.

Ação: Atualize Oracle WebLogic imediatamente ou bloqueie acesso externo

Ataque

Ataque Iran-Linked ao Stryker Arma Microsoft Intune para Deletar Dados em Milhares de Dispositivos

A gigante de dispositivos médicos Stryker (receita de $25B) sofreu um ataque cibernético global por grupo ameaça iraniano Handala/APT34. O ator armou Microsoft Intune para deletar massivamente dados de 56.000 dispositivos dos funcionários em 61 países, causando interrupção global a operações de pedidos, fabricação e envio.

Ação: Habilite MFA e aprovação multi-admin para operações destrutivas no Intune

Crítico

Google Corrige Duas Vulnerabilidades Zero-Days em Chrome Ativamente Exploradas

Google lançou atualizações de segurança para Chrome abordando duas vulnerabilidades de alta severidade ativamente exploradas: CVE-2026-3909 (CVSS 8.8) - write out-of-bounds na biblioteca gráfica Skia 2D; CVE-2026-3910 (CVSS 8.8) - implementação inapropriada no mecanismo V8. Google já corrigiu três zero-days ativamente explorados em Chrome desde início do ano.

Ação: Atualize Chrome para versão 146.0.7680.75 ou superior
08
Crítico

Nove Vulnerabilidades CrackArmor em Linux AppArmor Permitem Escalação para Root

Qualys TRU descobriu nove vulnerabilidades em AppArmor (nomeadas "CrackArmor") que permitem a usuários sem privilégios contornar proteções de kernel, escalar para root e quebrar isolamento de containers. A falha existe desde 2017 (versão v4.11) e afetou mais de 12,6 milhões de sistemas globalmente.

Ação: Aplique patches de kernel imediatamente em sistemas Linux afetados
