Olá, leitores! Esta semana foi marcada por ataques supply chain em larga escala atingindo ecossistemas críticos de desenvolvimento, um zero-day no cPanel explorado silenciosamente desde fevereiro, e uma falha lógica no kernel Linux que persiste desde 2017. Também cobrimos campanhas da Coreia do Norte usando IA para inserir malware. Vamos aos detalhes.

01
CríticoCVE-2026-41940

Zero-Day no cPanel & WHM explorado desde fevereiro

Uma vulnerabilidade crítica de bypass de autenticação no cPanel, WHM e WP Squared está sendo explorada ativamente desde fevereiro de 2026. A falha permite acesso administrativo a servidores vulneráveis sem autenticação. Um proof-of-concept já está disponível publicamente, o que amplifica o risco de exploração em massa.

O cPanel gerencia milhões de servidores no mundo. Servidores de shared hosting são particularmente vulneráveis, pois um único servidor comprometido pode afetar centenas de sites. A janela de dois meses antes da detecção pública sugere uso em ataques direcionados antes de se tornar conhecida.

Ação recomendada

Atualizar cPanel/WHM imediatamente; verificar logs de acesso desde fevereiro; restringir acesso ao painel administrativo via IP.

02
CríticoPyPI

PyTorch Lightning comprometido em ataque supply chain via PyPI

Atacantes comprometeram o popular pacote Python Lightning, publicando duas versões maliciosas (v2.6.2 e v2.6.3) no PyPI. O framework, com mais de 31.100 stars no GitHub, foi colocado em quarentena pelos administradores do PyPI. O ataque estende a campanha Mini Shai-Hulud, que antes atingiu pacotes npm do SAP.

O pacote malicioso inclui um diretório oculto _runtime com um downloader e um payload JavaScript ofuscado, disparado automaticamente na importação. O impacto é amplificado porque PyTorch Lightning é amplamente usado em projetos de machine learning e IA.

Ação recomendada

Verificar se usou pytorch-lightning==2.6.2 ou 2.6.3; se sim, rotacionar credenciais e tokens; usar pip install --no-deps para instalações verificadas.

03
Críticonpm

Pacotes npm oficiais do SAP comprometidos (Mini Shai-Hulud)

Uma nova campanha comprometeu pacotes npm oficiais do SAP — mbt@1.2.48, @cap-js/db-service@2.10.1, @cap-js/postgres@2.2.2 e @cap-js/sqlite@2.2.2. As versões comprometidas introduziram scripts de preinstall que baixam e executam um binário Bun de um repositório GitHub.

Scripts de preinstall são perigosos porque a execução acontece automaticamente durante npm install, sem interação do desenvolvedor. O Bun baixado segue redirecionamentos HTTP, executa imediatamente, estabelece persistência e exfiltra credenciais do ambiente de desenvolvimento.

Ação recomendada

Verificar package-lock.json para versões afetadas; usar npm audit; rotacionar credenciais SAP e tokens de desenvolvimento.

04
AltoLinux kernel

Linux “Copy Fail” — falha lógica dá root em todas as distros desde 2017

Foi publicado um exploit para uma escalação de privilégio local batizada de “Copy Fail”, que afeta kernels Linux desde 2017. A falha, no template criptográfico authencesn do kernel, permite que um atacante local não-privilegado obtenha root em todas as distribuições.

Por ser uma falha lógica no código criptográfico, persistiu por quase 9 anos sem detecção. O exploit publicado torna a exploração trivial. Servidores de shared hosting, containers com escape e ambientes multi-tenant são os mais vulneráveis.

Ação recomendada

Atualizar o kernel Linux imediatamente; priorizar shared hosting e ambientes multi-tenant; monitorar tentativas de escalação de privilégio.

05
AltoPromptMink

DPRK usa IA para inserir malware em pacotes npm

Pesquisadores descobriram código malicioso no pacote npm @validate-sdk/v2 após ele ser adicionado como dependência por um LLM. Listado como SDK utilitário, é na verdade um infostealer que rouba secrets do ambiente. A campanha foi batizada de PromptMink pela ReversingLabs e ligada ao grupo norte-coreano Famous Chollima.

É a primeira campanha documentada onde IA generativa foi usada para inserir malware em um ecossistema de pacotes — o pacote mostra sinais de ter sido “vibe-coded”. Faz parte da operação Contagious Interview e do esquema de IT Workers fraudulentos da Coreia do Norte.

Ação recomendada

Auditar dependências npm para @validate-sdk/v2; verificar integridade de pacotes antes de aceitar sugestões de IA; usar lockfiles.

06
AltoFirewall

SonicWall urge patches imediatos para vulnerabilidades em firewalls

A SonicWall divulgou vulnerabilidades em firewalls que permitem bypass de controles de segurança, acesso a serviços restritos e crash dos dispositivos. Firewalls são a primeira linha de defesa, e falhas neles podem comprometer toda a postura de segurança de uma organização.

Ação recomendada

Aplicar patches SonicWall imediatamente; verificar logs de firewall; considerar regras temporárias de mitigação se o patch não puder ser aplicado já.

07
MédioPython backdoor

DEEP#DOOR — backdoor Python stealth rouba credenciais de browser e cloud

A Securonix detalhou o framework de backdoor Python DEEP#DOOR, que estabelece acesso persistente e colhe informações sensíveis. A intrusão começa com um script batch que desabilita controles de segurança do Windows e extrai um payload Python embutido.

Usa múltiplos mecanismos de persistência — pasta Startup, chaves Run do registro, tarefas agendadas e subscrições WMI. O tunneling permite roubar credenciais de navegadores e cloud sem detecção baseada em rede.

Ação recomendada

Monitorar scripts batch que desabilitam controles; verificar persistência em Startup, registro e tarefas agendadas; detectar tunneling.

08
MédioRAT

EtherRAT via GitHub facades mira administradores e profissionais de DevOps

Identificada pelo Atos Threat Research Center, a campanha mira contas de alto privilégio de admins de TI, engenheiros DevOps e analistas de segurança. Usa SEO poisoning, distribuição dual-stage via GitHub e C2 baseado em blockchain para criar entrega resiliente.

O ataque começa com SEO poisoning em Bing, Yahoo, DuckDuckGo e Yandex; repositórios GitHub servem de fachada para o EtherRAT. A infraestrutura C2 em blockchain torna o takedown extremamente difícil.

Ação recomendada

Baixar ferramentas apenas de fontes oficiais; verificar hashes e assinaturas; desconfiar de resultados de busca para ferramentas administrativas.

Dica da semana

Três tendências preocupantes nesta edição: (1) ataques supply chain seguem em alta — a confiança cega em dependências de terceiros é um risco que não dá mais para ignorar; (2) a Coreia do Norte está usando IA generativa para criar e distribuir malware; (3) falhas em ferramentas críticas como cPanel e o kernel Linux mostram que problemas podem persistir por anos. Implemente verificação rigorosa de dependências (lockfiles, hashes, auditorias), mantenha patches em dia e desconfie de dependências sugeridas por IA.

Até a próxima semana. Fique seguro.
